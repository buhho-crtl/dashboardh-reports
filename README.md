# Dashboard H – Reports

This repository is dedicated to collecting **bug reports** and **feature requests** for the M365 Dashboard.

## How to report something

1. Go to the [Issues tab](../../issues/new/choose).
2. Choose **🐛 Bug Report** or **✨ Feature Request**.
3. Fill in the form with as much detail as possible.

That's it — the team will triage and label your report.
